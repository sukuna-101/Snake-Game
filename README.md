

Jogo Snake completo em um único arquivo Python usando Pygame.

## Requisitos
- Python 3.8+
- pygame

## Instalação
```
pip install -r requirements.txt
```

## Como jogar
```
python snake.py
```

## Controles
- Setas ou WASD: mover
- P: pausar
- R: reiniciar (na tela de game over)
- ENTER / ESPAÇO: iniciar / voltar ao menu
- ESC: sair

## Recursos
- Menu com 3 dificuldades (Fácil, Normal, Difícil com paredes)
- Velocidade que aumenta por nível a cada 50 pontos
- Comida bônus (roxa) que aparece aleatoriamente e vale 50 pontos
- High score salvo em `snake_highscore.json`
- HUD com Score, Nível, Dificuldade e Melhor pontuação
